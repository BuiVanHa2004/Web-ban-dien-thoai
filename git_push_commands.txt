REM ============================================
REM GIT COMMANDS - Push to GitHub main branch
REM ============================================

REM Step 1: Check current status
git status

REM Step 2: Add all changed files
git add .

REM Step 3: Commit with message
git commit -m "Fix chat system: unread count bug + Messenger-style delete (June 11 15:00 - June 12 04:17)"

REM Step 4: Pull latest changes from main (if any)
git pull origin main

REM Step 5: Push to main branch
git push origin main

REM ============================================
REM If you get conflicts during pull, resolve them then:
REM git add .
REM git commit -m "Merge conflicts resolved"
REM git push origin main
REM ============================================

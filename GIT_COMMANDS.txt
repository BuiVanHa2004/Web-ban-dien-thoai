BƯỚC 3: Commit với message rõ ràng
------------------------------------------------------
git commit -m "feat: Implement production-grade inventory management system

- Add inventory columns to ProductVariant: total_stock, reserved_stock, sold_stock, version
- Implement InventoryService with pessimistic locking
- Reserve stock on order creation (COD + BANK_TRANSFER)
- Confirm sale on payment success (BANK_TRANSFER) or delivery (COD)
- Release stock on order cancellation
- Add audit trail (OrderStockLog)
- Integrate with OrderService and PaymentService
- Add InventoryController API endpoints
- Prevent overselling with concurrent order handling
- Include database migration scripts"

------------------------------------------------------
BƯỚC 4: Push lên remote repository
------------------------------------------------------
git push origin main

------------------------------------------------------
BƯỚC 5: Verify trên GitHub/GitLab
------------------------------------------------------
Vào trang repository kiểm tra xem commit đã lên chưa

SAU KHI PUSH THÀNH CÔNG
------------------------------------------------------

QUAN TRỌNG: Phải chạy migration SQL trước khi deploy backend!

1. Đăng nhập MySQL của bạn:
   mysql -u your_username -p your_database

2. Chạy migration file đầu tiên:
   source C:/Doantotnghiep/backend/migration_add_inventory_columns.sql

   HOẶC copy nội dung file và paste vào MySQL Workbench

3. Chạy migration file thứ hai:
   source C:/Doantotnghiep/backend/migration_create_order_stock_logs.sql

4. Verify migration:
   DESC product_variants;
   DESC order_stock_logs;

5. Migrate dữ liệu hiện có:
   UPDATE product_variants 
   SET total_stock = COALESCE(quantity, 0),
       reserved_stock = 0,
       sold_stock = 0,
       version = 0
   WHERE total_stock = 0;

6. Kiểm tra:
   SELECT variant_id, quantity, total_stock, reserved_stock, sold_stock,
          (total_stock - reserved_stock - sold_stock) AS available_stock
   FROM product_variants LIMIT 10;

7. Nếu deploy trên RENDER:
   - Render sẽ tự động detect git push và rebuild
   - Đợi khoảng 3-5 phút
   - Kiểm tra logs trên Render dashboard

8. Test API sau khi deploy:
   GET https://datn-backend-d0et.onrender.com/api/inventory/variant/1

------------------------------------------------------
NẾU GẶP LỖI CONFLICT
------------------------------------------------------
git pull origin main
# Giải quyết conflict nếu có
git add .
git commit -m "resolve conflicts"
git push origin main

------------------------------------------------------
ROLLBACK NẾU CẦN
------------------------------------------------------
# Xem lịch sử commit
git log --oneline

# Quay về commit trước đó (thay COMMIT_HASH)
git revert COMMIT_HASH

# Hoặc reset về commit cũ (NGUY HIỂM!)
git reset --hard COMMIT_HASH
git push origin main --force
